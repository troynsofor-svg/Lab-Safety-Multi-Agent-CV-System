Evaluation & Results
1. Component‑Level Evaluation (Computer Vision Module)
This evaluates the YOLO perception component independently from the rest of the agent system.

Dataset
20 manually labeled test images

Classes: person, open_flame, chemical_container, PPE (lab coat, gloves, goggles)

Split: 15 evaluation images + 5 failure‑case stress tests

Metrics Computed
Precision — how many detections were correct

Recall — how many true objects were detected

F1 Score — harmonic mean of precision + recall

mAP@50 — mean average precision at IoU 0.5

IoU — intersection‑over‑union for bounding boxes

Inference speed — seconds per image

Interpretation
YOLOv8n is fast and reasonably accurate for general detection.

PPE detection is weaker because PPE is subtle and requires fine‑tuning.

Hazard detection (open flame, chemical container) performs well due to distinct shapes.

2. System‑Level Evaluation (Multi‑Agent Pipeline)
This evaluates the entire agent system end‑to‑end:

Input → Perception → Reasoning → Action → Output

Test Scenarios
20 total scenarios

Mix of:

Proper PPE

Task Success Rate

Failure Case Analysis (Required)
Your instructor wants honest, detailed explanations — here they are.

Failure Case 1 — Missing PPE not detected
Image: person wearing white shirt near flame
Expected: detect missing gloves
Actual: YOLO detected “person” but no PPE attributes
Reason:

YOLOv8n is not trained on PPE classes

White shirt looked similar to lab coat → false positive

Fix:

Fine‑tune PPE classifier

Add segmentation model for clothing detection

Failure Case 2 — Hazard not detected
Image: small alcohol burner partially occluded
Expected: detect “open_flame”
Actual: no hazard detected
Reason:

Flame was too small

Occlusion reduced confidence

YOLOv8n struggles with tiny objects

Fix:

Use YOLOv8s or YOLOv8m

Train custom hazard dataset

Increase input resolution
