# Evaluation & Results
1. Component‑Level Evaluation (Computer Vision Module)
This evaluates the YOLO perception component independently from the rest of the agent system.

Dataset
73 manually labeled test images

Classes: person, chemical, chemical bottles, face shield, mask, and PPE (lab coat, gloves, goggles)

# Dataset Split: 
Train set: 48 images + Valid set: 16 images + Test set: 9 images

Metrics Computed
Precision — how many detections were correct

Recall — how many true objects were detected

F1 Score — harmonic mean of precision + recall

mAP@50 — mean average precision at IoU 0.5

IoU — intersection‑over‑union for bounding boxes

Inference speed — seconds per image

Interpretation
YOLOv11 Object Detection (Nano) is fast and reasonably accurate for general detection.

PPE detection is weaker because PPE is indirect and demands fine‑tuning.

Hazard detections (open flame, chemical bottle, etc) perform properly because of distinct shapes.

2. System‑Level Evaluation (Multi‑Agent Pipeline)
This checks the whole agent system end‑to‑end:

Input → Perception → Reasoning → Action → Output

# Failure Case Analysis

# Failure Case 1 — Missing PPE not detected
Image: A human wearing a white shirt near a flame
Predicted: detect missing gloves
Actual: YOLO detected “human” but no PPE attributes
Reasons:
YOLOv11n was not trained on PPE classes
White shirt looked like a lab coat → false positive

Fix:
Adjust the PPE classifier
Include a segmentation model for clothing detection

# Failure Case 2 — Hazard not detected
Pictures: Little alcohol burner partially occluded
Predicted: detect “open_flame”
Actual: no hazard detected
Reason:
The flame was too tiny
Occlusion decreased confidence

Fix:
Use YOLOv8s, YOLOv8m, or another model.
Train and use a custom hazard dataset
Boost input resolution
